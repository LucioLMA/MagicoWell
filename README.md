# O Mágico Well

Protótipo do app de mágica com cartas. O jogador embaralha, escolhe uma carta em segredo, esconde debaixo da mesa, devolve no leque e embaralha de novo. O mágico erra duas vezes de propósito e acerta na terceira.

Para rodar, abra o `index.html` no navegador. Não precisa de instalação.
