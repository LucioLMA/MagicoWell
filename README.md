# O Mágico Well

Protótipo do app de mágica com cartas. O jogador embaralha, escolhe uma carta em segredo, esconde debaixo da mesa, devolve no leque e embaralha de novo. O mágico erra uma vez de propósito e, depois de um momento de suspense com rufar de tambor, acerta na segunda tentativa.

Para rodar, abra o `index.html` no navegador. Não precisa de instalação.
